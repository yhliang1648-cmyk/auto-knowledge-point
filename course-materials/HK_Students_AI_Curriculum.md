# 香港中小学生 AI 课程大纲
## 基于斯坦福 CS146S 改编

---

## 📚 课程总览

本课程基于斯坦福大学 CS146S《现代软件开发者》课程改编，专为香港中小学生设计，分为三个级别，循序渐进地引导学生掌握 AI 辅助编程技能。

---

# 🎨 小学级别（P4-P6）：AI 小创客

## 课程目标
- 认识 AI 和编程的基本概念
- 学会与 AI 对话来解决问题
- 培养计算思维和创造力
- 完成简单的互动项目

---

## 📖 课程模块（8周，每周1.5小时）

### **第1周：认识 AI 小助手**
**学习目标**: 了解什么是 AI，学会提问

**活动内容**:
- 🤖 认识 AI：观看有趣的 AI 应用视频
- 💬 学习提问：如何向 AI 提出清晰的问题
- 🎮 互动游戏：使用 ChatGPT 玩"20个问题"猜谜游戏
- ✏️ 实践：让 AI 帮你写一个故事开头

**学习成果**: 能够用完整的句子向 AI 提问

---

### **第2周：和 AI 一起讲故事**
**学习目标**: 学习给 AI 提供示例（K-shot Prompting 简化版）

**活动内容**:
- 📚 故事创作：给 AI 看几个例子，让它模仿
- 🎨 角色设计：创建故事中的人物
- 🖼️ 图画配对：用 AI 生成故事配图（简单介绍 DALL-E）
- 📖 成果分享：小组展示自己的 AI 故事

**学习成果**: 理解"示例"能帮助 AI 更好地工作

---

### **第3周：Scratch 遇上 AI**
**学习目标**: 在 Scratch 中使用简单的 AI 功能

**活动内容**:
- 🧱 Scratch 基础：认识积木式编程
- 🎙️ 语音识别：让 Scratch 听懂你的话
- 🎵 音乐创作：用 AI 生成背景音乐
- 🎮 小游戏：制作一个能回答问题的聊天机器人

**技术工具**:
- Scratch（https://scratch.mit.edu）
- Teachable Machine（图像识别训练）

**学习成果**: 完成一个会对话的 Scratch 角色

---

### **第4周：AI 图像魔法师**
**学习目标**: 了解 AI 如何识别和生成图像

**活动内容**:
- 👀 图像识别：训练 AI 认识物品（Teachable Machine）
- 🎨 AI 绘画：使用简化版 Stable Diffusion（如 Craiyon）
- 🖼️ 创意项目：设计自己的梦想房间/学校
- 🏆 作品展览：班级 AI 艺术展

**技术工具**:
- Teachable Machine
- Craiyon / AutoDraw
- Google Quick Draw

**学习成果**: 训练一个能识别3种物品的AI模型

---

### **第5周：AI 小帮手网页**
**学习目标**: 制作简单的网页，集成 AI 功能

**活动内容**:
- 🌐 HTML 入门：认识网页结构（标题、段落、按钮）
- 🎨 CSS 美化：让网页变漂亮
- 🤖 加入 AI：嵌入聊天机器人（使用 Chatbase 或 Voiceflow）
- 📱 主题选择：制作"班级小百科"或"宠物助手"

**技术工具**:
- CodePen（在线编辑器）
- Chatbase（无代码聊天机器人）

**学习成果**: 完成一个有 AI 聊天功能的网页

---

### **第6周：AI 安全小卫士**
**学习目标**: 认识网络安全和隐私保护

**活动内容**:
- 🔒 密码安全：什么是强密码？
- 🙈 隐私保护：不应该告诉 AI 的信息
- 🕵️ 识别危险：假信息和网络诈骗
- 🎮 安全游戏：通过游戏学习网络安全

**活动形式**:
- 角色扮演：模拟安全和不安全的对话
- 小组讨论：如何保护个人信息
- 制作海报：网络安全小贴士

**学习成果**: 能说出3条网络安全规则

---

### **第7周：AI 项目展示准备**
**学习目标**: 综合运用所学知识

**项目选择**（选一个）:
1. **AI 故事书**: 使用 AI 创作图文故事
2. **智能分类器**: 训练 AI 识别垃圾分类
3. **梦想设计师**: AI 辅助设计梦想教室
4. **聊天小助手**: 制作班级问答机器人

**活动内容**:
- 📋 项目规划：画出设计草图
- 🛠️ 动手制作：使用学过的工具
- 📝 准备展示：如何介绍自己的作品

**学习成果**: 完成一个小项目的原型

---

### **第8周：小创客展示日**
**学习目标**: 展示成果，培养演讲能力

**活动流程**:
- 🎤 项目展示：每人3分钟介绍作品
- 🌟 互相学习：参观同学的项目
- 🏅 颁发证书：AI 小创客认证
- 🎉 庆祝派对：总结学习收获

**家长参与**:
- 邀请家长观看展示
- 了解孩子的学习成果

**学习成果**: 能自信地介绍自己的 AI 项目

---

## 🎯 教学特色（小学）

- **视觉化学习**: 大量使用图片、动画和游戏
- **动手实践**: 每节课都有互动活动
- **趣味导向**: 以游戏和故事为载体
- **安全优先**: 强调网络安全和隐私保护
- **无压力**: 不强制编程，重在启发兴趣

# 🚀 初中级别（S1-S3）：AI 应用开发者

## 课程目标
- 掌握基础编程概念
- 学习多种 AI 提示技术
- 开发实用的 AI 应用
- 培养问题解决能力

---

## 📖 课程模块（12周，每周2小时）

### **第1-2周：Python 与 AI 对话**
**学习目标**: Python 基础 + AI API 调用

**Week 1 内容**:
- 🐍 Python 基础：变量、函数、条件、循环
- 📦 安装工具：Anaconda、VS Code
- 🤖 第一个 AI 程序：使用 OpenAI API
- 💬 简单对话：命令行聊天机器人

**Week 2 内容**:
- 📝 提示词技巧：如何写出更好的提示
- 🎯 Few-shot Learning：通过示例教 AI
- 🔄 改进对话：让 AI 回答更准确
- 📊 数据处理：处理 AI 返回的 JSON

**技术栈**:
- Python 3.10+
- OpenAI API（或免费的 Hugging Face API）
- VS Code

**项目**: 智能问答助手（帮助做功课）

---

### **第3-4周：智能笔记助手**
**基于 Stanford Week 2 改编**

**学习目标**: 构建自动化笔记整理工具

**Week 3 内容**:
- 📝 问题定义：如何整理课堂笔记？
- 🧠 思维链（Chain of Thought）：让 AI 逐步思考
- 📋 提取任务：从笔记中提取待办事项
- 🎨 简单界面：使用 Streamlit 制作网页

**Week 4 内容**:
- 🗂️ 数据存储：使用 JSON 保存笔记
- ✅ 任务管理：标记完成的任务
- 🎨 界面美化：让应用更好看
- 🚀 部署上线：分享给同学使用

**技术栈**:
- Python + Streamlit
- OpenAI/Claude API
- JSON 文件存储

**项目**: 课堂笔记智能整理器

---

### **第5-6周：AI 知识助手（RAG 入门）**
**基于 Stanford Week 1 RAG 改编**

**学习目标**: 构建能回答特定主题问题的 AI

**Week 5 内容**:
- 📚 RAG 原理：检索增强生成
- 🔍 向量搜索：如何找到相关信息
- 📖 文档处理：读取 PDF 和文本文件
- 🧪 实验：对比有无 RAG 的效果

**Week 6 内容**:
- 🎯 应用场景：DSE 备考助手 / 历史资料问答
- 📂 构建知识库：上传自己的学习资料
- 💡 智能问答：基于资料回答问题
- 📱 Web 应用：Streamlit 完整应用

**技术栈**:
- LangChain（简化版）
- FAISS 或 ChromaDB（向量数据库）
- Sentence Transformers（文本嵌入）

**项目**: DSE 科目问答助手

---

### **第7-8周：聊天机器人进阶**
**基于 Stanford Week 1 多种提示技术**

**Week 7 内容**:
- 🔧 Tool Calling：让 AI 调用外部工具
- 📅 实用工具：天气查询、计算器、日历
- 🌐 API 集成：调用真实的天气 API
- 🤖 智能代理：让 AI 自己决定用什么工具

**Week 8 内容**:
- 🎭 角色扮演：创建不同性格的 AI 助手
- 🔄 Self-Consistency：多次询问取最佳答案
- 🪞 Reflexion：让 AI 自我检查和改进
- 🏆 综合项目：多功能个人助手

**技术栈**:
- OpenAI Function Calling
- Weather API、Calculator API
- Streamlit

**项目**: 多功能智能助手（天气、学习、日程管理）

---

### **第9-10周：AI 网页应用开发**
**基于 Stanford Week 8 简化版**

**Week 9 内容**:
- 🌐 前端基础：HTML、CSS、JavaScript
- ⚡ Flask 框架：Python 后端开发
- 🔌 前后端连接：AJAX 请求
- 🎨 项目选择：待办事项 / 学习记录器

**Week 10 内容**:
- 🤖 集成 AI：在网页中调用 AI
- 💾 数据库：SQLite 基础（可选）
- 🎨 界面优化：使用 Bootstrap
- 🚀 部署：Replit 或 PythonAnywhere

**技术栈**:
- Flask（Python 后端）
- HTML/CSS/JavaScript
- Bootstrap（UI 框架）
- Replit（免费部署）

**项目**: AI 驱动的学习任务管理器

---

### **第11周：安全与测试**
**基于 Stanford Week 6 简化版**

**学习内容**:
- 🔒 输入验证：防止恶意输入
- 🛡️ API 密钥保护：环境变量的使用
- 🔍 错误处理：让程序更稳定
- ✅ 简单测试：验证功能是否正常
- 🕵️ 隐私保护：不记录敏感信息

**实践活动**:
- 检查自己项目的安全性
- 修复潜在问题
- 编写测试用例

**技术工具**:
- Python dotenv（环境变量）
- Try-except 错误处理
- 简单的单元测试

---

### **第12周：期末项目展示**
**学习目标**: 综合应用所学知识

**项目选择**（选一个深入开发）:
1. **智能学习助手**: RAG + 题目生成
2. **个人知识管理系统**: 笔记整理 + 智能搜索
3. **AI 辅导老师**: 特定科目问答系统
4. **创意工具**: AI 写作助手 / 创意生成器

**展示要求**:
- 📊 PPT 介绍：问题、方案、技术
- 💻 现场演示：展示核心功能
- 📝 代码说明：重要代码解释
- 🤔 反思总结：学到什么、未来改进

**评分标准**:
- 功能完整性（30%）
- 代码质量（20%）
- 创新性（20%）
- 展示表达（20%）
- 团队协作（10%）

## 🎯 教学特色（初中）
