🎯 課程特色

  • 基於斯坦福大學 2025 年最新 AI 課程改編

🚀 初中級別 (S1-S3)

成果：AI 應用開發者證書

🎓 高中級別 (S4-S6)

課時：16 週 × 3 小時

工具：Cursor、Claude Code、Warp

項目：全棧應用、MCP 服務器、多技術棧

成果：AI 工程師證書 + 作品集

🎨 小學級別：AI 小創客

適合年級：P4-P6 (小四至小六)

課程時長：8 週，每週 1.5 小時

教學方式：視覺化學習、遊戲化教學、無壓力探索

Week 1：認識 AI 小助手 🤖

學習如何向 AI 提問，使用 ChatGPT 玩猜謎遊戲，讓 AI 幫你寫故事開頭

Week 2：和 AI 一起講故事 📚

給 AI 看示例讓它模仿，創作角色，用 AI 生成故事配圖

Week 3：Scratch 遇上 AI 🧱

在 Scratch 中使用語音識別，用 AI 生成音樂，製作會對話的遊戲角色

Week 4：AI 圖像魔法師 👀

訓練 AI 認識物品（Teachable Machine），使用 AI 繪畫工具設計夢想房間

Week 5：AI 小幫手網頁 🌐

學習 HTML/CSS 基礎，製作有 AI 聊天功能的「班級小百科」網頁

Week 6：AI 安全小衛士 🔒

認識網絡安全、隱私保護，學習如何識別假信息和網絡詐騙

Week 7：AI 項目展示準備 🛠️

選擇項目（AI 故事書/智能分類器/梦想設計師/聊天小助手），動手製作

Week 8：小創客展示日 🎉

展示作品，互相學習，頒發「AI 小創客證書」，邀請家長參與

Scratch ChatGPT Teachable Machine Craiyon CodePen Chatbase

🚀 初中級別：AI 應用開發者

適合年級：S1-S3 (中一至中三)

課程時長：12 週，每週 2 小時

教學方式：項目驅動、實用導向、小組協作

Week 1-2：Python 與 AI 對話 🐍

Python 基礎 + OpenAI API 調用，製作命令行聊天機器人，學習提示詞技巧

Week 3-4：智能筆記助手 📝

構建自動化筆記整理工具，學習思維鏈提示，使用 Streamlit 製作網頁界面

Week 5-6：AI 知識助手（RAG）📚

學習檢索增強生成，構建 DSE 備考助手，處理 PDF 和文本文件

Week 7-8：聊天機器人進階 🤖

Tool Calling 讓 AI 調用工具（天氣、計算器），製作多功能個人助手

Week 9-10：AI 網頁應用開發 🌐

Flask 後端開發，前後端連接，製作學習任務管理器並部署上線

Week 11：安全與測試 🔒

輸入驗證、API 密鑰保護、錯誤處理、隱私保護

Week 12：期末項目展示 🏆

選擇深入項目（智能學習助手/知識管理系統/AI 輔導老師），PPT 展示 + 現場演示

Python OpenAI API Streamlit LangChain FAISS Flask HTML/CSS/JS Replit

🎓 高中級別：AI 工程師

適合年級：S4-S6 (中四至中六)

課程時長：16 週，每週 3 小時

教學方式：斯坦福標準、前沿工具、工程實踐

Week 1-2：提示工程大師 📝

6 種提示技術（Few-shot、CoT、RAG、Reflexion），構建 DSE 試題問答系統

Week 3-4：AI 輔助開發環境 💻

Cursor IDE 掌握，FastAPI + SQLite 完整項目，自動生成測試和文檔

Week 5-6：模型上下文協議（MCP）🔌

MCP 服務器開發，封裝真實 API（GitHub、天氣、Notion），Vercel 部署

Week 11-12：安全掃描與修復 🔍

Week 13-14：AI 代碼審查 👀

Graphite Diamond 使用，人工 vs AI 審查對比，4 個 PR + 詳細報告

Week 15-16：多技術棧快速開發 ⚡

Bolt.new 應用生成，MERN、Django、Rails 三個版本，Vercel 部署

🏛️ 斯坦福 CS146S 原課程

📖 課程信息

課程名稱：CS146S: The Modern Software Developer

開設時間：斯坦福大學 2025 年秋季

授課教師：Mihail Eric

官網：themodernsoftware.dev

GitHub：課程作業倉庫

🎯 課程目標

教授學生如何使用最新的 AI 驅動工具進行軟件開發，包括新一代 IDE（Cursor）、終端（Warp）、代碼審查和測試平台（Coderabbit、Qodo），重點關注何時以及為何信任 AI 驅動的工作流程。

8 週課程結構

Week 1：Prompting Techniques

K-shot、Chain-of-Thought、Tool Calling、Self-Consistency、RAG、Reflexion

Week 2：Action Item Extractor

使用 Cursor 構建 FastAPI + SQLite 應用，LLM 驅動的提取，自動化測試和文檔

Week 3：Build a Custom MCP Server

實現 Model Context Protocol 服務器，封裝外部 API，本地或遠程部署

Week 4：The Autonomous Coding Agent

Claude Code 自動化：自定義命令、CLAUDE.md、SubAgents、MCP 集成

Week 5：Agentic Development with Warp

Warp Drive 工作流、多代理並發、Git worktree 管理

Week 6：Scan and Fix Vulnerabilities

Semgrep 靜態分析、SAST/Secrets/SCA、修復安全漏洞

Week 7：AI Code Review Using Graphite

Graphite Diamond AI 審查、人工 vs AI 對比、4 個 PR 實踐

Week 8：Multi-Stack Web App Build

Bolt.new 應用生成、3 個技術棧（MERN、Django、Rails）、完整部署
