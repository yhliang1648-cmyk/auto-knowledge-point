# ⚡ Cloudflare Worker 一键部署指南

## 🎯 您只需选择以下任一方式部署

---

## 方式一：命令行部署（推荐 - 最快）⭐

### 第 1 步：在项目目录运行部署脚本

```bash
cd /home/user/auto-knowledge-point/cloudflare-workers
./deploy.sh
```

### 第 2 步：按照提示操作

脚本会自动：
- ✅ 检查 Node.js 环境
- ✅ 安装 Wrangler CLI（如果未安装）
- ✅ 引导您登录 Cloudflare
- ✅ 部署 Worker
- ✅ 显示 Worker URL

### 第 3 步：复制 Worker URL

部署成功后，您会看到：
```
✅ 部署成功！
您的 Worker URL:
https://qwen-api-proxy.YOUR-USERNAME.workers.dev
```

**请复制这个 URL！**

### 第 4 步：更新网站配置

打开 `index.html`，找到第 **851-852** 行，修改：

**修改前：**
```javascript
const CLOUDFLARE_WORKER_URL = '';  // 空的
const USE_CLOUDFLARE_WORKER = false;
```

**修改后：**
```javascript
const CLOUDFLARE_WORKER_URL = 'https://qwen-api-proxy.YOUR-USERNAME.workers.dev';  // 👈 粘贴您的 URL
const USE_CLOUDFLARE_WORKER = true;  // 👈 改为 true
```

同时在第 **856** 行，修改：
```javascript
const USE_CORS_PROXY = false;  // 👈 改为 false，停用临时代理
```

### 第 5 步：提交代码

```bash
cd /home/user/auto-knowledge-point
git add index.html
git commit -m "Enable Cloudflare Worker proxy for Qwen API"
git push -u origin claude/connect-github-repo-Y7Rcj
```

### 第 6 步：验证

1. 等待 2-5 分钟（GitHub Pages 部署）
2. 访问：https://yhliang1648-cmyk.github.io/auto-knowledge-point/index.html
3. 按 **Ctrl+Shift+R** 强制刷新
4. 打开浏览器控制台（F12），应该看到：`✅ 使用 Cloudflare Worker 代理（推荐）`
5. 测试上传 PDF/Word 文件

## 方式二：网页界面部署（简单直观）

### 第 1 步：登录 Cloudflare

访问：https://dash.cloudflare.com/

### 第 2 步：创建 Worker

1. 左侧菜单 → **Workers & Pages**
2. 点击 **Create Application**
3. 选择 **Create Worker**
4. 命名：`qwen-api-proxy`（或任意名称）
5. 点击 **Deploy**

### 第 3 步：编辑代码

1. 点击 **Edit Code** 或 **Quick Edit**
2. 删除默认的所有代码
3. 打开文件：`cloudflare-workers/qwen-api-proxy.js`
4. 复制全部内容（Ctrl+A, Ctrl+C）
5. 粘贴到 Worker 编辑器中
6. 点击右上角 **Save and Deploy**

### 第 4 步：获取 URL

部署成功后，页面会显示您的 Worker URL：
```
https://qwen-api-proxy.YOUR-USERNAME.workers.dev
```

**请复制这个 URL！**

### 第 5 步：更新网站配置

与方式一的第 4 步相同，修改 `index.html` 第 851-852 行和第 856 行。

### 第 6 步：提交代码

与方式一的第 5 步相同。

## ❓ 常见问题

### Q1: 部署 Worker 需要付费吗？
**A:** 不需要！Cloudflare Workers 免费套餐每天提供 100,000 次请求，完全够用。

### Q2: 我没有 Node.js，可以部署吗？
**A:** 可以！使用方式二（网页界面部署），不需要任何命令行工具。

### Q3: 部署后网站还是显示 "CORS 公共代理"？
**A:** 请检查：
1. 是否已强制刷新浏览器（Ctrl+Shift+R）
2. GitHub Pages 是否完成部署（等待 2-5 分钟）
3. `index.html` 配置是否正确修改

### Q4: Worker 部署成功，但 API 调用失败？
**A:** 请检查：
1. Worker URL 是否正确填入 `index.html`
2. Qwen API Key 是否有效
3. 浏览器控制台是否有错误信息

### Q5: 可以同时保留两种方案吗？
**A:** 可以！通过 `USE_CLOUDFLARE_WORKER` 和 `USE_CORS_PROXY` 开关可以随时切换。
