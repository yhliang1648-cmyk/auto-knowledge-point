🚀 Cloudflare Pages 部署指南

目标：將 DSE RAG 系統部署到 Cloudflare Pages，讓全世界都能訪問！

第一步：打開 Cloudflare Dashboard

👉 點擊這裡打開 Cloudflare Dashboard

步驟 1: 登錄 Cloudflare

  • 使用你的 Cloudflare 帳號登錄
  • 如果沒有帳號，點擊 "Sign Up" 免費註冊

步驟 2: 進入 Workers & Pages

  • 在左側菜單中，找到並點擊 Workers & Pages
  • 如果看不到，點擊左上角的 ☰ 菜單圖標

步驟 3: 創建 Pages 項目

  • 點擊右上角的藍色按鈕 Create application
  • 重要！選擇 Pages 標籤（不是 Workers）
  • 點擊 Connect to Git
⚠️ 注意：一定要選擇 Pages 標籤，不是 Workers！

步驟 4: 連接 GitHub

  • 點擊 Connect GitHub 或 Connect account
  • 授權 Cloudflare 訪問你的 GitHub（如果首次使用）
  • 在倉庫列表中找到：yhliang1648-cmyk/auto-knowledge-point
  • 點擊倉庫旁邊的 Begin setup

步驟 5: 配置構建設置

填寫以下信息：

  • Project name: dse-rag-system （或任何你喜歡的名字）
  • Production branch: claude/connect-github-repo-Y7Rcj
  • Framework preset: None
  • Build command: 留空（不填）
  • Build output directory: . （只輸入一個點）
💡 提示：Build output directory 填寫一個點 . 表示根目錄

步驟 6: 部署！

  • 點擊底部的 Save and Deploy 按鈕
  • 等待 1-2 分鐘，系統會自動構建和部署
  • 看到綠色的 "Success" 就表示完成了！

🎉 部署成功後

你會看到一個網址，類似於：

https://dse-rag-system.pages.dev

或者 https://你的項目名.pages.dev

點擊這個網址就能訪問你的 DSE RAG 系統了！

步驟 7: 測試網站

  • 打開部署完成的網址
  • 嘗試搜索一些關鍵詞，如 "氣候變化"、"數學"
  • 查看搜索結果（目前使用模擬數據）

📋 常見問題

Q: 找不到我的 GitHub 倉庫？

A: 點擊 "Configure GitHub App" 重新配置權限，確保 Cloudflare 可以訪問該倉庫。

Q: 部署失敗怎麼辦？

A: 檢查以下幾點：

  • Build output directory 是否填寫為 .
  • Production branch 是否正確
  • 查看部署日誌中的錯誤信息

Q: 部署後網站是空白的？

A: 確認：

  • Build output directory 設置為 .
  • index.html 在倉庫的根目錄
  • 重新部署一次試試

🔄 自動部署

配置完成後，每次你推送代碼到 GitHub，Cloudflare 會自動重新部署！

非常方便！🚀
