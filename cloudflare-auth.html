🔐 Cloudflare 授權

為了將 DSE RAG 系統部署到 Cloudflare Pages，需要您授權訪問權限

📌 步驟 1: 點擊授權按鈕

點擊下方按鈕，將在新標籤頁打開 Cloudflare 授權頁面

🚀 立即授權 Cloudflare
⚠️ 重要提示：授權後，頁面可能會顯示"無法訪問此網站"或重定向錯誤。這是正常的！請忽略錯誤信息。

📌 步驟 2: 使用 API Token（替代方案）

如果上述 OAuth 方式不工作，可以使用 API Token：

  1. 訪問: Cloudflare API Tokens
  2. 點擊 Create Token
  3. 選擇 Edit Cloudflare Workers 模板
  4. 點擊 Continue to summary → Create Token
  5. 複製生成的 Token
  6. 告訴我這個 Token（我會用來部署）

📌 方案 3: 直接使用 Cloudflare Dashboard（最簡單）

如果命令行授權有困難，建議使用瀏覽器手動部署：

  1. 訪問: Cloudflare Dashboard
  2. Workers & Pages → Create → Pages → Connect to Git
  3. 選擇倉庫: yhliang1648-cmyk/auto-knowledge-point
  4. 配置並部署（參考之前的部署指南）
