## 颜色含义

### 光线颜色
- **蓝色实线**: 平行于主光轴的光线
  - 经透镜后过焦点(凸透镜)或发散(凹透镜)
- **紫色实线**: 经过光心的光线
  - 方向不变,直线传播
- **品红色实线**: 经过焦点(或其延长线)的光线
  - 经透镜后平行于主光轴
- **虚线**: 虚像的反向延长线
  - 表示光线的反向延长,不是实际光路

### 物体和像
- **绿色箭头**: 物体
  - 竖直向上的箭头
- **红色箭头**: 实像
  - 实线箭头,表示实际成像
- **橙色箭头**: 虚像
  - 虚线箭头,表示虚拟成像

### 焦点标记
- **实心红点**: 凸透镜的实焦点
- **空心红点**: 凹透镜的虚焦点

## 操作详解

### 1. 调整物距 (Object Distance)

**功能**: 改变物体到透镜的距离

**操作**:
- 拖动"物距"滑块
- 范围: 1 cm ~ 50 cm
- 步长: 0.5 cm

**观察重点**:
- 凸透镜:
  - 物距从大到小移动时,像从小变大
  - 穿过焦点时,实像变虚像
- 凹透镜:
  - 像的大小随物距变化
  - 始终是虚像

### 2. 调整焦距 (Focal Length)

**功能**: 改变透镜的聚焦能力

**操作**:
- 拖动"焦距"滑块
- 范围: 2 cm ~ 30 cm
- 步长: 0.5 cm

**观察重点**:
- 焦距越小,透镜"能力"越强
- 焦点位置随焦距改变
- 成像规律随焦距变化

### 3. 调整物高 (Object Height)

**功能**: 改变物体的高度

**操作**:
- 拖动"物高"滑块
- 范围: 0.5 cm ~ 8 cm
- 步长: 0.1 cm

**观察重点**:
- 像的高度按放大率变化
- 不影响成像类型
- 便于观察放大/缩小效果

### 4. 切换透镜类型

**功能**: 在凸透镜和凹透镜之间切换

**操作**:
- 点击右下角单选按钮
  - "凸透镜": 会聚透镜
  - "凹透镜": 发散透镜

**观察重点**:
- 透镜形状变化
- 焦点变化(实焦点 vs 虚焦点)
- 成像规律完全不同

## 典型实验

### 实验1: 探究凸透镜成像规律

**目标**: 理解物距与成像的关系

**步骤**:
1. 设置焦距 f = 10 cm
2. 依次设置物距:
   - u = 40 cm (u > 2f)
   - u = 30 cm (u > 2f)
   - u = 20 cm (u = 2f)
   - u = 15 cm (f < u < 2f)
   - u = 12 cm (f < u < 2f)
   - u = 10 cm (u = f)
   - u = 8 cm (u < f)
   - u = 5 cm (u < f)

**记录表格**:
| 物距 u (cm) | 像距 v (cm) | 放大率 | 成像类型 | 倒立/正立 |
|------------|------------|--------|---------|----------|
| 40         |            |        |         |          |
| 30         |            |        |         |          |
| ...        |            |        |         |          |

### 实验2: 测量透镜焦距

**原理**: u = 2f 时,v = 2f,成等大实像

**步骤**:
1. 设置焦距 f = 15 cm (先隐藏)
2. 调整物距,找到成等大实像的位置
3. 此时 u = 2f,测量 u
4. 计算 f = u/2

**验证**:
- 计算得到的焦距与设定值比较
- 误差应该很小(<0.1 cm)

### 实验3: 比较凸透镜与凹透镜

**目标**: 理解两种透镜的不同

**步骤**:
1. 设置相同参数(f=10cm, u=20cm, h=3cm)
2. 先观察凸透镜成像
3. 切换到凹透镜观察
4. 比较异同点

**对比**:
|        | 凸透镜        | 凹透镜      |
|--------|--------------|------------|
| 焦点   | 实焦点       | 虚焦点     |
| 成像   | 可能实像/虚像 | 只有虚像   |
| 倒立   | 可能倒立     | 总是正立   |
| 放大   | 可能放大     | 总是缩小   |
| 应用   | 照相机、投影仪| 近视眼镜   |

### 实验4: 光路追踪

**目标**: 理解三条特殊光线

**步骤**:
1. 设置合适参数,使成像清晰
2. 逐条观察三条光线:
   - 蓝色: 平行光线
   - 紫色: 过光心光线
   - 品红: 过焦点光线
3. 验证三条光线在像点汇聚

**注意**:
- 虚像时,是反向延长线汇聚
- 光线遵循光的反射/折射定律
- 理解作图法的物理意义

## 常见问题

### Q1: 为什么有时候看不到像?

**A**: 可能的原因:
1. 物距等于焦距(u = f),不成像
2. 像在图形范围外,调整参数使其进入视野
3. 虚像的虚线不明显,仔细观察

### Q2: 虚线是什么意思?

**A**: 虚线表示:
1. 虚像的光线(实际不存在,是反向延长线)
2. 辅助光线(指向焦点但未到达)
3. 虚焦点的连线

### Q3: 如何快速找到特定成像?

**A**: 快捷设置:
- 照相机效果: f=10, u=30 (倒立缩小实像)
- 投影仪效果: f=10, u=15 (倒立放大实像)
- 放大镜效果: f=10, u=5 (正立放大虚像)
- 近视眼镜: 切换到凹透镜

### Q4: 参数设置有什么技巧?

**A**: 建议:
1. 先设定焦距(通常10-15cm较合适)
2. 再调整物距观察不同情况
3. 物高设为焦距的1/3左右(便于观察)
4. 从远到近移动物体,观察像的变化

### Q5: 如何理解放大率?

**A**: 放大率 m = v/u = h'/h
- |m| > 1: 放大
- |m| = 1: 等大
- |m| < 1: 缩小
- m < 0: 倒立(实像)
- m > 0: 正立(虚像)

## 学习路径

### 初学者 (第1-2天)
1. 了解界面和基本操作
2. 运行快速开始的4个练习
3. 完成实验1,填写记录表格
4. 理解凸透镜成像规律

### 进阶 (第3-5天)
1. 完成实验2,学会测量焦距
2. 完成实验3,比较两种透镜
3. 完成实验4,理解光路追踪
4. 自己设计实验参数

### 高级 (第6-7天)
1. 阅读源代码 `lens_physics.py`
2. 理解透镜公式推导
3. 运行示例代码 `examples/basic_usage.py`
4. 修改代码,添加新功能
